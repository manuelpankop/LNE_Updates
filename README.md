# LNE_Updates

Update-Pakete für den Liniennetzplan-Editor. Das Programm lädt sie selbst
(Menü Hilfe → Nach Updates suchen).

Die Releases enthalten keine vollständigen Programme, sondern nur
verschlüsselte Unterschiede zu bereits ausgelieferten Fassungen sowie eine
signierte Paketliste (`manifest.json`, `manifest.sig`).
